# Arcanova Brand Guide

## Name

Use `Arcanova` everywhere user-facing.

Avoid old names:

- `AUSTRAL`
- `Austral`
- `AUSTRAL Cancún Premium`
- `Riviera Cancún`
- `Riviera Cancun`
- `Cancún Premium`

## Public Copy Direction

Arcanova should feel premium, clear, warm, and trustworthy. It should avoid sounding like a generic tour reseller.

Preferred language:

- curated experiences
- premium travel planning
- personalized quote
- direct human support
- flexible itinerary
- trusted local coordination

Avoid:

- cheap tour wording
- overpromising availability
- implying online payment is processed if it is not
- hardcoded destination assumptions unless the business intentionally focuses on that destination
