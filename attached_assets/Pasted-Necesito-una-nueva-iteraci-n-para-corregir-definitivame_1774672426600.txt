## Objetivo funcional

### Email

Quiero que al tocar “Email”:

* abra correctamente el cliente de correo
* complete destinatario
* complete asunto
* complete cuerpo con el resumen de la cotización o interés
* funcione tanto desde el flujo del carrito/cotizador como desde accesos generales de contacto si existen

### Facebook / Messenger

Quiero priorizar este orden:

1. **Messenger directo** si existe un enlace confiable del negocio
2. Si no se puede abrir Messenger con mensaje prellenado de forma estable:

   * abrir el destino correcto del negocio (Messenger o página)
   * copiar automáticamente el mensaje al portapapeles
   * mostrar feedback claro: “Mensaje copiado, pegalo en Messenger/Facebook”
3. No quiero que mande simplemente a un perfil genérico que no sirve para conversar

### Footer

Quiero que el footer muestre:

* iconos o links correctos a redes
* email visible/clicable
* canal de Facebook/Messenger correcto
* y que todo salga de una configuración centralizada de contacto, no hardcodeado en varios componentes

## Alcance técnico

### 1. Revisar y corregir el email

Auditar:

* generación de `mailto:`
* encoding del `subject`
* encoding del `body`
* uso de `a.click()`
* comportamiento en popup/modal/iframe preview
* si algún close del modal o handler está cortando la acción
* si el email configurado es correcto en todos los lugares

Quiero que el canal email funcione desde:

* botón del carrito/cotizador
* cualquier CTA general si existe
* footer

### 2. Centralizar configuración de contacto

Crear o consolidar una fuente única tipo:

```ts
export const CONTACT_CHANNELS = {
  email: "info.ixchelexperience@yahoo.com",
  whatsapp: "5491138475846",
  facebookPageUrl: "...",
  messengerUrl: "...",
  instagramUrl: "...",
};
```

Todos los componentes deben consumir esta misma fuente:

* carrito
* botón flotante
* footer
* modales/contacto
* cualquier CTA secundario

### 3. Corregir estrategia Facebook/Messenger

Revisar exactamente qué dato existe hoy:

* perfil personal
* página
* enlace `m.me`
* share link
* URL incorrecta

Quiero implementar la mejor estrategia posible según el dato disponible:

#### Caso ideal

* existe `m.me/...` o link de Messenger válido del negocio
* abrir ese link

#### Caso fallback

* copiar mensaje al portapapeles
* abrir página correcta del negocio
* mostrar un estado o mensaje visual claro explicando qué hacer

No quiero redirecciones rotas ni páginas de error.

### 4. Integrar el footer

Revisar el footer actual y agregar/ordenar:

* Email
* Facebook / Messenger
* WhatsApp si corresponde
* otras redes reales del negocio

Requisitos:

* links visibles y clicables
* nombres/íconos correctos
* consistencia visual con el sitio
* mobile friendly
* no duplicar configuraciones

### 5. Mensajes

Mantener el sistema actual de mensajes del carrito, pero asegurar que:

* email use el resumen correcto
* Facebook/Messenger use el mismo resumen o una versión adaptada
* no haya caracteres rotos
* no haya mensajes vacíos
