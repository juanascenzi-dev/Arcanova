# PROMPT PARA REPLIT — AUSTRAL · Cancún Premium Tourism Website (V3)

## CONTEXTO DEL PROYECTO

Necesito una landing page / sitio web completo para **AUSTRAL Cancún Premium**, un servicio de turismo premium en Cancún y la Riviera Maya, México. El nombre "Austral" es un guiño a nuestro origen argentino — sutil pero reconocible para los nuestros. Vendemos excursiones exclusivas (yates privados, cuatriciclos en la selva, bungee jumping, visitas VIP a Chichén Itzá), traslados de lujo, y armamos viajes completos personalizados para nuestros clientes. Nos diferenciamos porque siempre tenemos planes alternativos para días de lluvia (spa maya, cata de tequilas, cenotes techados, clases de cocina). El servicio es premium y se ofrece a turistas de todo el mundo.

---

## REQUERIMIENTOS TÉCNICOS

- **Framework**: React + Vite (o Next.js si preferís SSR/SEO)
- **Styling**: Tailwind CSS o CSS Modules — diseño luxury, NO genérico
- **Idiomas**: El sitio DEBE ser bilingüe **Español / Inglés** con un toggle de idioma visible en el navbar. El idioma por defecto debería detectarse del navegador del usuario (si es "es" → español, sino → inglés). El usuario puede cambiar manualmente en cualquier momento y la preferencia debe persistir (localStorage).
- **Responsive**: Mobile-first, debe verse perfecto en celulares, tablets y desktop
- **Animaciones**: Scroll-triggered fade-ins, hover effects en cards, transiciones suaves
- **Despliegue**: Listo para deploy en Replit / Vercel / Netlify

## HERO CON CARRUSEL DE IMÁGENES (NUEVO — IMPORTANTE)

El hero NO debe tener una sola imagen estática. Debe tener un **carrusel automático de imágenes de fondo** con transición fade suave.

### Comportamiento:
- **5-6 imágenes** de fondo que rotan automáticamente
- Cada imagen se muestra durante **10 segundos**
- Transición entre imágenes: **crossfade suave de 1.5 segundos** (una se desvanece mientras la otra aparece)
- Las imágenes deben tener un **overlay oscuro semitransparente** (rgba(10,22,40,0.55)) encima para que el texto sea legible
- El carrusel funciona en loop infinito
- NO mostrar dots/indicators ni flechas — es automático y sutil
- El texto del hero (título, subtítulo, CTAs, stats) se mantiene estático encima — solo cambia el fondo

### Implementación técnica sugerida:
```jsx
// Stack de imágenes absolutas con z-index y opacity transition
const [currentSlide, setCurrentSlide] = useState(0);

useEffect(() => {
  const interval = setInterval(() => {
    setCurrentSlide(prev => (prev + 1) % heroImages.length);
  }, 10000); // 10 segundos
  return () => clearInterval(interval);
}, []);

// Cada imagen:
{heroImages.map((img, i) => (
  <div key={i} style={{
    position: 'absolute', inset: 0,
    backgroundImage: `url(${img})`,
    backgroundSize: 'cover',
    backgroundPosition: 'center',
    opacity: currentSlide === i ? 1 : 0,
    transition: 'opacity 1.5s ease-in-out',
  }} />
))}
// Overlay oscuro encima
<div style={{ position: 'absolute', inset: 0, background: 'rgba(10,22,40,0.55)' }} />
```

### IMPORTANTE para performance:
- Precargar la primera imagen (`<link rel="preload">` o eager loading)
- Las demás cargar lazy
- Usar `w=1600&q=80` para las hero (resolución grande) vs `w=800&q=80` para cards

- **Color**: Dorado (#C9A84C) sobre fondos oscuros, azul oscuro (#0A1628) sobre fondos claros

- **Composición en navbar**: [Ícono timón] + texto "AUSTRAL" en Playfair Display bold + subtítulo "Cancún Premium" en DM Sans pequeño debajo

### Referencia de estructura del SVG del timón:
```
- Círculo exterior (la rueda)
- 8 radios/manijas que salen del centro (como los handles del timón)
- Círculo interior pequeño (el hub central)
- Las manijas terminan en pequeñas esferas o puntas redondeadas
- Líneas de trazo (stroke), no relleno sólido, para un look elegante y abierto
```

El SVG debe verse bien tanto a 36px (navbar) como a 120px (footer o hero). Crear el logo como componente reutilizable `<HelmLogo />` que acepte props de `size` y `color`.
